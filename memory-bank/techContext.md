# Tech Context: Kück's Kälbermanager

## Technologies & Languages
- **Frontend:**
  - HTML5 (Semantic markup, modal dialogs, responsive layout)
  - CSS3 (Custom properties/variables, flexbox/grid, Google Fonts: *DM Sans* and *Space Grotesk*)
  - JavaScript (ES6+, asynchronous fetch API, DOM manipulation)
- **Backend & Persistence:**
  - Google Apps Script (V8 Runtime, `SpreadsheetApp`, `ContentService`)
  - Google Sheets (Cloud database, single-cell JSON storage)
- **Client Storage:**
  - Browser `localStorage` (Key: `kaelbermanager-config-v1` storing `{ sheetId, apiUrl }`)

## Tools & Environment
- **IDE:** Visual Studio Code
- **Platform:** Windows (PowerShell)
- **Version Control:** Git
